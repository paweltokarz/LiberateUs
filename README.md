# Liberate Us

**Liberate Us** to niezależna, alternatywna aplikacja na Androida do obsługi wiadomości w systemie **Librus Synergia**.

Projekt powstał z myślą o wygodniejszym korzystaniu ze szkolnej korespondencji. Stawia na przejrzysty interfejs, sprawną obsługę wiadomości oraz możliwość dostępu do wcześniej pobranych treści także bez połączenia z internetem.

Liberate Us jest projektem nieoficjalnym, rozwijanym niezależnie od dostawcy systemu Librus Synergia.

## Możliwości aplikacji

- **Wiadomości odebrane** — przeglądanie korespondencji i odczytywanie pełnej treści wiadomości.
- **Wiadomości wysłane** — przeglądanie wysłanej korespondencji, w tym pełnej treści wiadomości.
- **Wersje robocze** — tworzenie, zapisywanie i edytowanie szkiców wiadomości.
- **Pisanie i wysyłanie** — przygotowywanie wiadomości z wyborem adresatów.
- **Odpowiadanie** — szybkie przygotowanie odpowiedzi z cytatem oryginalnej wiadomości.
- **Pamięć lokalna** — przechowywanie pobranej korespondencji na urządzeniu.
- **Dostęp offline** — odczytywanie danych zapisanych wcześniej w pamięci aplikacji.
- **Powiadomienia** — okresowe sprawdzanie nowych wiadomości w tle.

Aplikacja jest rozwijana na bieżąco. Dostępność i działanie poszczególnych funkcji mogą zależeć od zmian wprowadzanych w systemie Librus Synergia.

# Liberate Us — English

**Liberate Us** is an independent, alternative Android application for handling messages in the **Librus Synergia** system.

The project aims to make school communication more convenient through a clear interface, practical messaging features, and offline access to previously downloaded content.

Liberate Us is an unofficial project developed independently of the Librus Synergia service provider.

## Features

- **Inbox** — browse received messages and read their full contents.
- **Sent messages** — view sent correspondence, including full message bodies.
- **Drafts** — create, save and edit message drafts.
- **Compose and send** — write messages and select recipients.
- **Replies** — prepare replies with the original message quoted.
- **Local storage** — retain previously downloaded messages on the device.
- **Offline access** — read messages already stored locally.
- **Notifications** — periodically check for new messages in the background.

The application is under active development. Changes to the Librus Synergia system may affect the availability or behavior of individual features.
