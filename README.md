# Liberate Us

**Liberate Us** is an independent, alternative Android client for **Librus Synergia**, focused on convenient access to school messages and a straightforward, modern interface.

The application provides an alternative way to work with Librus messages while keeping previously downloaded information available locally.

Liberate Us is an unofficial community project. It is not affiliated with, endorsed by, or supported by Librus.

## Features

- Reading incoming messages and their full contents
- Viewing sent messages and drafts
- Composing, saving and sending messages
- Replying to received messages
- Local storage of previously synchronized messages
- Offline access to locally available information
- Background checking for new messages and notifications

The project is under active development. Features and compatibility may change between versions.

## Building from source

The project uses Kotlin, Jetpack Compose and Gradle.

1. Install Android Studio and the appropriate Android SDK.
2. Clone this repository.
3. Open the project in Android Studio.
4. Build the `debug` variant or run the application's Gradle build tasks.

Do not commit `local.properties`, signing keys or account credentials.
